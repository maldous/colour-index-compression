# Integrated CIX runtime candidate

This maintained runtime combines fresh-input generic and specialised complete
archives. It is under integration and is not yet a qualified distribution.
Research datasets, benchmark orchestration, saved streams and result certificates
are not runtime inputs. Python and pinned native backends are explicit runtime
dependencies. The ordinary staged `cix` command will invoke this package.

Implementation and validation follow the approved plan in
`docs/research/2026-10-04-automatic-specialised-models/`. No current integrated
Silesia result is claimed until the frozen one-pass validation completes.
