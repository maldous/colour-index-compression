## Objective and attribution

Minimise actual stored bytes, with exact inversion. Each field is charged once:
layout/phase/length, transform/predictor choices and parameters, backend IDs,
local state or dictionaries, exact residuals/exceptions, payload lengths,
framing/termination/checksum. A residual codes violations exactly; it is not a
free exception mechanism. Decoder construction/search costs are runtime costs.
Discovery, rejected trials and backend comparisons count as encoder work.

Geometry means a byte mapping, not recovered semantic fields. Rank/support
experiments and changed-support transforms are reported separately. Same
admissible set with the same ordering has the same rank requirement.
