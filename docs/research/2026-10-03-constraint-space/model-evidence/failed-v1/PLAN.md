# Same-space model-description instrument — pre-execution freeze

Prior-art destruction is recorded in `../sdl-prior-art.md`: hash-consing,
ROBDD sharing, factor graphs, constraint languages and two-part model codes
are established. This is a control instrument, not a newly named theory.

Hypothesis: shared structural selectors can reduce naive flat metadata, but
ordinary bit packing or a compact existing model representation may erase the
advantage. Compare exactly identical canonical local state sets; never attribute
rank-space changes to model-description efficiency.

Frozen scope: existing five qualified equality/count inputs and models converted
from their actual stored labels; four new synthetic inputs in two unrelated
predicate combinations (bounded count plus parity, then endpoint XOR as a
third relation); and empty/mono/arbitrary-byte fallbacks. Development and held-out
b/parameters/seeds/alphabets are fixed together before any execution. Source
model templates are explicit prescribed examples; forced representation tests
are not input-discovery evidence. Native discovery is separately qualified.

Eight native representations: Raw, combinadic subset, occupancy bitset, run
list, canonical ordered ROBDD, flat predicates, bit-packed flat predicates,
and automatic shared-selector interning. All model bytes/IDs/order/references
are serialized. Common MSL1 overhead19bytes; exact mixed-radix rank for the same
ordered local table is identical. Generic decoder software is excluded
consistently with ordinary reference archives; all per-input assets are paid.

Membership/enumeration is limited to b<=12, at most4096assignments. Native
wire decoders are independently checked by a Python integer/truth-set oracle,
not a Python codec. Source alphabet, length, local model and byte ordering are
stored. Fresh archive-only native decoding verifies SHA-256 reconstruction.
Raw accepts arbitrary bounded input. No claim of unrestricted tractable CSP.

Ordinary metadata-compression controls are actual MDC1 archives: zstd1.5.5 -19
thread1 and bzip2 1.0.8 -9 applied to flat/shared/ROBDD model bytes, with length,
codec, original header/checksum and complete framing paid. Native framing
extract/rebuild plus standard native decompression and fresh MSL decode must
restore the identical archive/source. The MDC1 total is31+compressed_model+
rank bytes. These are backend/metadata controls, not native-model advances.

Complete input controls for new four cases: zstd19/thread1, xz9e/thread1,
bzip2-9, gzip-n-9 and frozen Rust CIX d3a2 BEST/thread1/1536MiB. Existing five
case controls are reused only with immutable source/settings/artifact identities.
One observation per cell. No wall/CPU time comparisons with imported Squash.
No corpus benchmarks, acquisition, public Site or production deployment.

Report model/rank/complete bytes, scope of selected-candidate kernels versus
full Auto/discovery cost, construction/compile/COUNT/rank/unrank times, GNU
CPU/RSS and whole-phase memory/temp receipts. Small timings are descriptive,
not statistically established speed gains. Publish all losses, raw fallbacks,
unsupported routes and reference failures.

Use existing shared WaveScheduler CPU8 lease and one-core quota,2GiB memory,
swap0,64MiB active work cap; build120s, generator40s, aggregate batch720s,
perexperimentalchild10s/perreference120s. Stop on verification failure; preserve
failed source/freeze/raw receipts, assign a new identity before changing code.
Active artifacts are monitored under benchmark-work; small evidence logs are
outside its footprint and explicitly disclosed.

Promotion requires generic discovery, same-state-space exact checks, practical
resource evidence, fresh reconstruction, complete wins against appropriate
controls and frozen held-out replication. Even then, metadata packing/dedup
is level0/1 on the user's ladder and not a new compression theory. Every method
remains isolated from production. SDD/d-DNNF/ZDD/grammar implementations and
broader primitive-language synthesis stay unqualified/queued, not silently
counted as implemented.
