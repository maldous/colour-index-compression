# Controlling research direction: model descriptions

Latest user steering supersedes prospective novelty in fixed-space ranking.
Same admissible space plus the same uniform dense index cannot produce a rank
advantage by renaming its construction. The equality/count experiments are
complete; do not vary them further to rescue that claim.

Primary question: can a generic, automatically discovered, shared structural
model description define useful exact spaces more cheaply than established
representations, while COUNT/RANK/UNRANK stay practical?

For fixed Ω compare complete model descriptions directly. For actual input
compare complete archive bytes, including model, parameters, compiled state,
exceptions, rank, padding, checksum and framing. Generic decoder code is shared
software; no source-specific dictionary, generator identity or hidden assets.

Prior art first: graph/factor/constraint languages, knowledge compilation,
grammars/SLPs, finite-state and weighted automata, relational models, succinct
structures, MDL/MML/algorithmic statistics, synthesis/DSLs/probabilistic
programming and tensor/factor decompositions. Ask whether an existing language
expresses exactly the same model at equal or lower paid cost. Do not rename it.

Five required instruments:

1. Same space, different established descriptions for existing qualified Ω.
2. Unrelated combinations and frozen held-out model-description sharing.
3. Three-way sharing versus two-way/independent descriptions.
4. Automatic reusable-component discovery; no hand-chosen winning expression.
5. Complete archive comparison with strong established controls.

For each: verify identical Ω and canonical rank order, record model/rank/total
bytes, discovery/construction/count/rank/unrank time, peak memory and decoder
complexity. Keep tradeoffs and losses. Use one observation per cell under the
user's timing instruction; no averages. Existing verified baselines may be
reused only for identical bytes/settings/code identities.

Novelty ladder:0ordinarymetadata compression;1automaticdeduplication;
2newpracticalrepresentation;3newdiscoveryalgorithm;4newtractablerepresentation
class;5newgeneraltheory. Levels0–3 are not new compression theory.

Preserve generic input-derived policy and exact arbitrary bytes. Experiments
remain isolated; no production CIX changes, broad benchmarks, acquisition,
public Sites, workflow/Actions use, or old Hutter runs. Root leases bounded
local computation through the existing scheduler; agents prepare disjoint
prior-art/control/design documents in parallel. Completed evidence is committed
and pushed privately after checking Actions remain disabled.
