Production is unchanged. RXP1 source `bedd86e7cea40e8cf0ec7ba0780439d7d032ac991aab258ea4eedd2085eeb6e0`
was frozen before execution. Native Zstd 1.5.5, level +19 C API (CLI -19),

## What changed

The completed escape mechanism is retained. RXP1 additionally discovers an
arithmetic progression in exceptional positions or stores actual compressed
u16 gaps. Three policies auto/colex/zstd-gaps were encoded; progression is an
auto-selected physical map, not a forced matched portfolio measurement.
All 49 new complete archives restored exactly in fresh native processes;
independent table, position, compliant-rank and exception-payload readback
passed. Nine malformed archives were rejected. Existing controls were rehashed,
not rerun. Full commands, one-observation timings and RSS are in raw/metrics.

## Attribution and break-even

For an unchanged learned record model, REX uses 35 bytes model/header/CRC;
RXP uses 36. Every compliant rank and exceptional record bit is unchanged.
The weak-six archive is exactly `36 + 4 + 723 + 91 = 854` B.
The old colex map was 83 B; a paid start:u16/step:u16 map is 4 B.
The net saving is `83 - 4 - 1 = 78` B versus REX; versus the stronger ordinary
histogram archive the saving is 71 B.

A progression is worthwhile against this matched REX format precisely when
`ceil(ceil(log2 binomial(r,e))/8) > 5` (plus actual applicability and unchanged
other fields). For both 16-violation examples the colex map is 16 B, giving
11 B net. Irregular record permutations preserve vocabulary and usage counts
but remove progression structure: auto chooses colex and loses the new byte.
This directly isolates position-description benefit rather than fallback.
Compressed gaps do not improve the auto winner on this grid.

## Exactness and limits

The decoder reads stored map type/counts, never searches or compresses. Zstd
maps must contain exactly one complete frame and exactly 2e decoded bytes;
positive subsequent gaps and bounds establish ordered, unique positions.
BigUint ranks are exact. Unranking uses a descending binomial recurrence, with
at most r position steps. AP overflow, zero step, invalid start, lengths, IDs,
CRC, truncation and backend trailing bytes were rejected. The tested all-FF
rank has slack: weak-six compliant rank is 5,781 bits in a 5,784-bit field,
so rejection genuinely exercises the impossible-rank bound.

Batch wall 86.964 s, CPU 86.086 s, native per-cell GNU peak RSS <=3 MiB;
whole batch sampled cgroup high-water 121,503,744 B (a sampled lower bound,
not true peak), active-work high-water 5,412,491 B. Controls and discovery are
included in batch work; encoding/decoding are separately recorded per cell.
No timing averages or imported performance rankings were used.

## Closest prior art / strongest claim

Combinadics, arithmetic-progression descriptions and compressed integer gaps
are established. This is a verified generic implementation and automatically
selected model-description improvement on a narrow synthetic family—not a
new entropy bound, new state-space rank advantage or broad generalisation.
Noise robustness depends on cheaply describable exception positions and a
surviving input-derived record model. Ordinary weighting remains stronger on
the irregular development negative.
