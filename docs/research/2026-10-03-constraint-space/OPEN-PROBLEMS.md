# Restricted questions requiring further evidence

These are project research questions, **not certified open problems in the
mathematical literature**. None is currently classified as a new theory.

## Q1: Paid heterogeneous intersection under a frontier bound

Can equality/affine relationships and exact histogram allocation share a
compact completion-count state whose description plus rank beats both a
direct relationship model and a practical predictor on the same arbitrary
bytes? The binary component/histogram DP is already known combinatorics.
The unresolved project issue is generic discovery, decoder metadata and the
computational cost of heterogeneity. A bounded frontier is an explicit resource
restriction, not a theorem of closure under arbitrary useful constraints.

Falsification: no savings after partition/parameter/state costs; a shorter
ordinary direct model; frontier/table growth beyond budget; missed exact
reconstruction. Do not promote a payload-only gain.

## Q2: Which representation should be transmitted?

Compare a predicate description with deterministic decoder recompilation
against a stored BDD/decomposable circuit/bounded-frontier certificate.
Minimise complete bytes subject to decoder time/memory. Existing compilation
languages already solve representation and counting subproblems. Any possible
Six contribution must be a specific discovery/certificate selection algorithm,
not calling an existing BDD a new IR.

Falsification: circuit/order bytes erase the rank reduction, compilation
requires unbounded work, or an established symbolic coder reproduces the result
with equal or lower complete cost.

## Q3: Joint search that survives direct-model simplification

Search small finite grammars for individually unprofitable constraints with a
profitable complete intersection. Before attributing a win to interaction,
compare a directly expressible equivalent set. The strongest analytical
all-zero witness already fails this control: direct ALL_ZERO is shorter.
The qualified eight-bit family has7,810positive volume interactions but zero
paid pair wins. Higher-order exploration is not yet executed.

Falsification: every apparent interaction is merely shared header cost,
redundancy removed by a standard normal form, or a direct known predicate.
Affine constraints with independently paid rows admit a safe nonwin rejection
rule; do not waste research by demanding positive volume synergy there.

## Q4: Exact indexing versus approximate discovery

Separate a cheap encoder-only shortlist from a decoder-complete exact
representation. URPILS approximations cannot define dense rank intervals, but
known arithmetic coding or certified upper-bound enumeration can be exact
without dense ranks. Compare their actual costs, counting memory and decode
time. Approximation is not intrinsically forbidden; unproved cardinality/rate
claims are forbidden.

Falsification: the exact representation never repays its work/description,
or deterministic approximate-probability coding already matches the gain more
cheaply. No novelty follows from adding an exact backend to model discovery.

## Execution boundary

Prior-art destruction must precede each new algorithm claim. Freeze grammar,
settings, objective, sources and budgets before a new tiny experiment. Retain
failed and negative trials. Expand to real compression comparisons only after
independent rank values and actual archive grammar are qualified. Production
integration and ordinary optimisation remain paused. Corpus acquisition,
public publication and GitHub Actions remain outside scope.
