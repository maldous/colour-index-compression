# Silesia-only encoder comparison

The active comparison uses the 12 complete official members listed at [Matt Mahoney's Silesia page](https://mattmahoney.net/dc/silesia.html). Each original has a publisher-listed MD5 checked before freezing and a local SHA-256 recorded in `silesia-v3/coverage.json`. No fragments, synthetic substitutes, or cross-file training are used.

The comparison is seven methods (`CIX`, gzip, bzip2, Zstandard, XZ/LZMA2, Brotli, paq8px) × 12 files × three separate profiles (`fast`, `current`, `size`): 252 cells. The five-layer PAQ `-12L` size setting is prelaunch-excluded at an estimated 29 GB RAM against the shared 12 GB limit, leaving 240 scheduled cells. Each eligible cell has one complete cold encode and one archive-only decode; timing values are single observations, not medians. The phases include process launch and normal file reads/writes. The source path is unavailable to the decoder. Exact output length and SHA-256 restoration are required for a ranked result.

CIX is itself adaptive and tests original-byte streams made with all six other methods when eligible, then its native CIXG1 candidates. It records the route and selects the smallest complete archive whose decode was verified. CIXB1's 47-byte envelope is charged. Fast/current use bounded candidate budgets and do not imply an exhaustive guarantee; PAQ can time out or exceed the two-gigabyte per-cell memory cap. The size profile excludes only PAQ for the published working-set limit; its other eligible direct codecs and native routes are tested. Direct reference rows are standalone output without CIX wrapper bytes.

All trials share four physical cores, at most 12 GB scheduled RAM and 4 GB temporary storage; each cell is capped at one core, 2 GB RAM, 100 MB temporary storage and 300 seconds, with cgroup swap disabled. The machine's host swap may exist, but experimental cgroups have `MemorySwapMax=0`. Reported process peak values are GNU-time observations for direct leaf commands; cgroup sampled high-water is retained as a separate lower-bound measure. The public view labels the memory caveat.

The initial v1 candidate freeze was superseded before launch because it lacked PAQ integration and capped inputs at 16 MiB. The v2 run is retained but not ranked: its direct encoder commands omitted the input path, and its CIX path exposed a verified-fallback abort on a failed PAQ candidate. v3 corrects both issues and is the only active Silesia result set. No other corpus or Actions job is part of this work.
