CIX command manual

NAME

cix - create a lossless CIX archive

SYNOPSIS

cix [-1 ... -9 | --fast | --best] [-c] [-f] [-k] [-o file] [file]

DESCRIPTION

cix compresses one file or standard input into a self-describing CIX archive. With a named input, the default output name appends .cix. Inputs are retained by default. Use - as FILE for standard input; use -c for standard output. CIX stores one byte stream per invocation; use an archiver such as tar when preserving a directory tree.

EFFORT AND RESOURCES

-1 ... -9

Set compression effort. The default is -6.

--fast

Use effort 1 for lower compression latency.

--best

Use effort 9 for the broadest bounded archive search. With no explicit --memory, BEST raises the memory admission limit to 2 GiB. Decoding, testing, and listing also start at 2 GiB unless an explicit limit is supplied. Eligible whole-file native BEST work can use a 15-minute allowance plus up to 45 minutes based on input size. Direct external-library calls can add time and are not preemptible, so this is not a total wall-time limit.

--memory SIZE

Set the maximum admitted working memory. SIZE accepts the size syntax accepted by the command, such as 512MiB. FAST and the default profile start at 512 MiB. An explicit value is never raised automatically.

--threads N

Set the worker limit from 1 through 20. The default is up to four available CPUs. More than one worker is supported only for native CIXG1/CIXG2 block or candidate selection.

--parallelism blocks|candidates

Choose parallel work across ordered blocks or among candidate trials within a block.

BASIC OPTIONS

-c

Write the archive to standard output.

-o FILE

Write the archive to FILE.

-f

Replace an existing output file.

-k

Accepted for compatibility. Inputs are retained by default.

-h, --help

Show command usage.

--version

Show the version and supported container identifiers.

FORMAT AND EXPERT CONTROLS

These controls constrain the encoder and can exclude otherwise eligible candidates. They are intended for diagnosis and controlled integration.

--format auto|cixg1|cixg2|cixm6|cixf1

Select or constrain the output container. The default, auto, selects among eligible native containers. CIXM6 and CIXF1 are encoding-only formats and cannot be combined with route selection, external candidates, or portfolio selection. CIXF1 requires a named input so its basename can be stored. An explicit non-auto format forces a compatible whole-container wire and excludes unrelated automatic carriers.

--route auto|raw|runs|composition|lz|predictor|bwt|stride|phrases|ppm|mixture|deflate

Constrain the native route. Some routes need more memory: LZ and mixture need at least 16 MiB, and PPM needs at least 64 MiB.

--backend NAME

Constrain the nested substream backend. Supported names are cix, raw, runs, ppm, mixture, deflate, hybrid, range, count-range, context-range-o1-b4, context-range-o1-b8, context-range-o2-b8, and huffman. Some versioned substream coders require CIXG2 or automatic format selection. This is native-container tuning: without an explicit non-auto --format, independent automatic candidates remain eligible and do not claim to use the selected nested backend.

--block-size SIZE

Set the maximum uncompressed block size. CIXG1 frames are limited to 65536 bytes; larger requests are reduced to that limit with a diagnostic. The legacy --block form accepts a byte count. This is native-container tuning; it restricts native block candidates without forcing the automatic search to one container wire.

--history SIZE

Request retained model history. The current native routes do not support a nonzero value and reject it.

--independent-blocks

Request model reset boundaries. It conflicts with retained history and is not available for CIXM6/CIXF1 or external/portfolio encoding.

--stream

Require streaming operation. Streaming uses bounded framed candidates; it cannot be used with whole-input external or portfolio selection.

--flush-interval DURATION

Flush framed partial blocks after an idle interval while encoding. It is not a decoding option. For non-seekable input, it requires Unix poll support.

--profile fast|default|size

Choose an external profile or map a native auto/CIXG1/CIXG2 encode to effort 1, 6, or 9. It cannot be combined with a numeric effort option.

--portfolio fast|default|size

Use bounded whole-input CIXB1 portfolio selection, comparing eligible native and direct external candidates before choosing one completed archive. This is whole-input portfolio selection, not per-symbol predictive mixing. It requires a named bounded input and conflicts with streaming, route, external, and profile controls.

--external CODEC

Explicitly wrap a direct external codec in CIXB1. It is an encoding-only, named-input operation and conflicts with streaming and route selection.

--explain

Report candidate costs and decisions.

--verbose

Report aggregate search statistics and resource exclusions.

EXIT STATUS

0 indicates success. A nonzero status indicates invalid arguments, I/O failure, resource admission failure, interruption, or compression failure.

uncix(1), cixcat(1)

NAME

uncix - restore, test, or inspect a CIX archive

SYNOPSIS

uncix [-c] [-f] [-k] [-t|-l] [-o file] [archive]

DESCRIPTION

uncix restores a CIX archive to its original byte stream. With a named archive, the default output name removes a final .cix suffix when present. Existing outputs are not replaced unless -f is supplied. Omit ARCHIVE or use - to read an archive from standard input.

OPTIONS

-c

Write restored bytes to standard output.

-o FILE

Write restored bytes to FILE.

-f

Replace an existing output file.

-k

Accepted for compatibility. Input archives are retained by default.

-t

Test archive integrity without writing restored bytes.

-l

List archive information on standard error while restoring.

-h, --help

Show command usage.

--version

Show the CIX version and supported container identifiers.

RESOURCE LIMITS

The decoder starts with a 2 GiB working-memory admission limit unless an explicit limit is supplied. Use ordinary operating-system process limits when restoring untrusted archives. Compression options, including effort, route, format, block-size, profile, and parallelism, are rejected while decoding.

SECURITY

Archives from untrusted sources are untrusted input. Use uncix -t when an integrity check is needed without writing restored bytes.

SEE ALSO

cix(1), cixcat(1)

NAME

cixcat - restore a CIX archive to standard output

SYNOPSIS

cixcat [archive]

DESCRIPTION

cixcat is the streaming-output form of uncix. It restores ARCHIVE, or standard input when ARCHIVE is omitted or -, to standard output. It is intended for pipelines.

For example:

cixcat backup.tar.cix | tar -x

OPTIONS

-h, --help

Show command usage.

--version

Show the CIX version and supported container identifiers.

RESOURCE LIMITS

The decoder starts with a 2 GiB working-memory admission limit unless an explicit limit is supplied. Apply normal operating-system process limits when using CIX in an automated pipeline.

EXIT STATUS

0 indicates success. A nonzero status indicates invalid input, an integrity failure, I/O failure, resource admission failure, or interruption.
