Final count/dictionary and seeded-space theory screen
2026-10-04

Finding: a short shared seed CAN select a useful nonlinear coordinate space and permit exact lower-dimensional coding when the data actually follows that space. The constructed positive example demonstrates this with every seed/prefix/coordinate/framing cost paid. Neither the fixed dictionary nor the 32 seeded spaces improved the five tested real Silesia samples. No new production route is justified by this screen. No universal impossibility or exhausted-method claim is made.

Interpretation of the original count question
The remembered break-even point matches a 31-bit binary mask, not 31 arbitrary bytes. With four bits for a minority count0..15 and one bit for its colour, the complete count/index core is5+ceil(log2(C(31,k))) bits. This reconstructs the remembered threshold; it is not a claim that an original historical wire specification was independently recovered. If31bytes was meant literally, the same reasoning applies to a binary classification or individual bit plane and all other byte information must also be represented.

Why a fixed hash/generator dictionary cannot shorten every middle-count pattern
For k=15 there are300,540,195 distinct31-bit masks. Any collision-free fixed-length index covering all of them still needs29bits; the5count/colour bits take this core to34bits. Renaming the index a hash, seed, coordinate or generator-function identifier does not reduce the number of distinguishable possibilities. A many-to-one projection needs a residual identifying the preimage; a function producing many answers also needs an answer-selection parameter. Variable-length codes may make some patterns shorter, at the cost of other patterns. A public fixed decoder/dictionary can avoid per-archive table bytes but does not avoid the selector information.

Dictionary experiment
For each k=10..15 the fixed dictionary contains465 distinct cyclic arithmetic-progression masks modulo31. A9-bit index selects one. The decoder regenerates the table from a fixed rule; no corpus dictionary or learned bytes are used. A matched direct function uses5bits of start and4bits of step-minus-one: also9bits, so the lookup is not an extra source of information. Count/colour and token choice are paid. Raw, count-only, direct-parameter, Zstd9, zlib9 and XZ1 controls use the same13-byte length/method/CRC frame. No prior encoded-space or padding-reuse mechanism was revisited.
Constructed progression data:31,757-byte raw frame becomes15,373bytes with either dictionary indices OR direct parameters. The dictionary supplies no advantage over the equivalent short function. Matched uniform middle-count data expands to32,781bytes versus31,757raw. There are real dictionary hits in ooffice (79of16,912blocks), but their savings do not approach stronger ordinary compression.

Seeded-space experiment (the additional user possibility)
The fixed family has identity plus31 seed-derived bijections on31-bit integers. Each seed hashes to exact xor-shift, odd modular multiply/add, rotation and xor-shift parameters. This is nonlinear over binary linear coordinates, reversible with finite integer arithmetic, and does not require inverting a cryptographic hash. The transmitted5-bit seed identifies which fixed function to regenerate.
Each block, or each64-block group, may use a zero-prefix coordinate subspace or a common-prefix subspace. Dimension, shared prefix if needed, seed and every remaining coordinate are transmitted; failing groups use literal fallback. Controls include identity coordinates, a learned affine binary basis with its anchor/basis/coefficients fully paid, raw bytes and Zstd9/XZ1. Additional arbitrary higher-dimensional lifts or general manifold solvers were not implemented.
Constructed positive:4,096words are generated by applying the inverse of fixed seed7 to random17-bit coordinates. They look unstructured in original coordinates and do not benefit from the measured generic or affine-basis controls. The best control is15,885bytes. A seed shared per 64words produces8,813bytes,44.52%smaller, with exact restoration. Paying a seed for every word is materially worse (best compressed per-word form13,394bytes). This deliberately model-matching construction validates possibility, not prevalence in natural data.
Already-visible17-bit coordinates are best coded by the identity control at8,773bytes; the seed model costs8,813bytes. This exposes the seed overhead instead of attributing an existing low-dimensional structure to a new projection. Uniform data has no benefit.

How higher-dimensional embeddings fit
For a chosen seed let E_s be an injective lift and P_s a lower-dimensional projection. The actual code must identify s, projected coordinates z=P_s(E_s(x)), and any residual distinguishing x within that projection fibre. A lift may expose relations, but it does not reduce the number of original states. If a31-bit domain is projected to17binary coordinates, at least one fibre contains16,384 inputs; a uniform balanced construction needs14morebits within its fibre. In the synthetic positive the high14coordinates are known zero by an admitted model, so there is only one relevant preimage and those bits need not be sent. The real opportunity is a short model for a sufficiently populated restricted support, especially with a shared seed. This does not prohibit more expressive nonlinear, relational, higher-dimensional or data-derived models. It does not demonstrate them either.

A finite search-cost example makes the boundary concrete. For an independent uniform group of 64 words, a fixed reversible map puts every word into a zero-prefix 17-bit subspace with probability 2^(-14*64). Across the 32 tested seeds the union bound is at most 2^-891. This calculation does not assume independence between seeds. It applies only to this fixed zero-prefix model and a uniform source, not all projections or real source distributions. The constructed positive instead obeys that model by design. A cheap shared index helps when the source has that relationship; adding arbitrary embedding dimensions does not itself make the relationship more likely.

Validation and decision
All168 retained physical candidate/control archives passed fresh-process exact restoration; source, frozen-plan and retained-frame hashes were reread and verified. The first run included8,283small exhaustive/boundary combinatorial checks,230control frames, all5,580dictionary patterns with both colours and7malformed-frame rejections. The second included6,788map inverse/frame checks. These are research implementations, not hardened or installed production codecs, and fresh processes reuse the reference implementation rather than an independent decoder implementation.
Scheduler totals were4.89seconds and3.90seconds respectively on core12, each capped60seconds and512MB with no swap. There were no failed/repeated performance runs. No main CIX/SQL/vendor source, host tuning or full RC benchmark was changed.
Final disposition: retain the conditional seeded-coordinate mechanism as valid research, but do not add the tested dictionary/projection routes to this RC. There is no real-data gain in this finite screen. Do not expand seed counts, dimensions, function grammars or corpus search to chase these outcomes before the existing release work. Future research remains possible; the finite release decision is complete.
