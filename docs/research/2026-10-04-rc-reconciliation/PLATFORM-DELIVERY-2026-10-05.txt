Recommended bounded validation path
Use private hosted runners for Linux ARM64, Windows x64, macOS ARM64 and macOS
Intel, with the current Linux x86-64 checks as the control. The official current
labels are ubuntu-24.04-arm, windows-2022, macos-15 and macos-15-intel. Record
the actual image release, CPU architecture and toolchain; labels are not
immutable environment identities. Standard private runners offer differing
memory amounts (8 GB Linux/Windows, 7 GB Apple Silicon, 14 GB Intel Mac), so
PAQ admission must leave room for the host and build tools. Availability in the
official catalogue does not prove this account can dispatch every runner.

Validation stages
1. Actual runner/toolchain/resource inventory.
2. Target source build, clean relocated CLI/SDK use, aliases, round trips,
   malformed data, path/cancellation/resource contracts.
3. Platform-specific PAQ isolation and complete pinned provider operations.
4. Cross-platform archive-only exact restoration with retained codec versions.
5. Package installation, upgrades, uninstall and offline dependency closure.
6. Signed/notarized public distribution later, after identities and release
   approval exist. No public release follows from the validation authority.
