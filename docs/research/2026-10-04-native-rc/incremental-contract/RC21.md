# RC21 native incremental contract

`core::incremental` emits existing independent CIXG1 framing while input is
still open. `process` reports consumed and produced bytes plus explicit
`NeedsInput`, `NeedsOutput`, or `Finished` state. A bounded input block and one
pending frame provide backpressure; `flush` closes a partial independent block,
and `finish` emits the existing checksummed END frame.

The paired decoder retains one CIXG1 frame and caller-undrained output. It
decodes each complete frame through the established native decoder, so normal
`core::decode` remains compatible. This contract does not claim CIXM6 or
full-engine retained-history streaming.
