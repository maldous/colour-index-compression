# RC02 core extraction

`src/core.rs` exposes side-effect-free `encode`, `decode`, and buffer entry
points. Its implementation module is crate-private, so consumers cannot reach
the executable adapter through `core`, `codec`, or the crate root.

`src/cli.rs` owns parsing, standard-input/file opening, stdout routing, signal
installation, diagnostics and named-file whole-archive selection. Its same-CIX
candidate worker is an explicit CLI callback passed to portfolio selection;
ordinary `core::{encode,decode}` calls cannot locate or spawn a process.

The remaining engine-local option validation and atomic-output helpers are
crate-private implementation debt, not an SDK surface. The next scheduled
foundation snapshot must compile this split and run focused embedding/C ABI
checks before RC02 can be accepted.
