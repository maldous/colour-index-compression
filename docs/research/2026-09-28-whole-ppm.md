# Whole-input PPM diagnostic

This experiment tests whether model resets and limited context order leave
generic compression gains. It is not a leaderboard result or production codec
change. `benchmarks/ppm_whole_input.py` tries the same PPM orders 3, 5 and 7 for
each byte sequence, with no filename or format-dependent selection. Each frame
includes a five-byte experimental magic/version, varint original length, CRC32
and the existing PPM payload (including its model selector).

The initial complete-input tournament passed all 12 round trips. Best frames:

| Input | Current CIX stream | Experimental PPM frame | Best order |
| --- | ---: | ---: | ---: |
| alice29.txt | 43,147 | 41,202 | 5 |
| fields.c | 2,960 | 2,742 | 7 |
| grammar.lsp | 1,122 | 1,086 | 5 |
| Artificial random.txt | 75,089 | 76,181 | 3 |

These are complete physical frame sizes, not entropy estimates. The incumbent
must remain available. The experimental magic differs from CIXM6, allowing a
future decoder to distinguish representations without an additional selector.
The production decoder does not yet support this experimental frame.

Raw results are in `2026-09-28-ppm-whole-input.jsonl`. The experiment can be
reproduced with:

```sh
OMP_NUM_THREADS=1 .venv-pypy/bin/python -m benchmarks.ppm_whole_input \
  --manifest results/leaderboard/runtime-manifest.json \
  --output results/leaderboard/ppm-whole-input-repeat.jsonl
```

A broader tournament over all 29 prerequisite members is running in four local
workers, with manifests, per-worker JSONL and full compressed artifacts in
`results/leaderboard/ppm-whole-tier1/`. It uses the same three orders everywhere.
Each generated artifact is decoded and compared before its result is accepted.
No full prerequisite tournament claim may be made until all 87 cases finish.

Whole-input context dictionaries are unbounded with input size. Before applying
this approach to Silesia, it needs a generic bounded-memory block policy or a
qualified resource bound. Do not launch large whole-file jobs on the assumption
that the small-input runtime and memory behavior extrapolate.
