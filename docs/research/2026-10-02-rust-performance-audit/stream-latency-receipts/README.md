# Native CIXG1 streaming receipts

`receipt.json` is generated by `benchmarks/cix_stream_latency_probe.py` from
the frozen `integrated-8865bfbcc` CIX and UNCIX binaries. It records the exact
commands, binary and resolved-library hashes before and after execution,
deterministic local input identity, byte timing before input EOF, exact
restoration, malformed-archive rejection, and a bounded slow-consumer pipe
case.

This is focused local streaming correctness and latency evidence. It is not an
isolated-host corpus qualification, compression benchmark, or ranking.
