# Frozen first implementation evaluation

Owner: `/root`. Hypothesis: a bounded generic selector plus reversible
representations can provide a more useful size/time tradeoff than the existing
generic research stream. This is new implementation evidence, not revival of
the historical Silesia/Hutter tournaments.

Acquisition cutoff and usable members are frozen in `acquisition-cutoff.json`.
The original code/configuration/evidence is recoverable at
`research-before-generic-pipeline-20260930` and the external baseline TAR.
The completed molecular/numerical receipts and negatives remain unchanged.
Their hydrogen/schema contributions do not become generic routing detectors.
Transferable ideas implemented here are causal numerical corrections,
history-derived phrase references, bounded conditional prediction, shared
substreams, and paid composition/order coding.

Development inputs are predeclared 16 KiB prefixes of FCBench `msg_bt_f64`,
`astro_mhd_f64`, and the supplied Compression Golf JSONL. Held-out selector
evaluation uses disjoint 16 KiB regions of `astro_pt_f64`, `rsim_f32`, and Golf.
These are named subsets, not whole corpora. The full Canterbury/Calgary/
Artificial local member set is a separate regression gate. No new full
Silesia, enwik9 or Hutter run is launched. RAI/GDCC and incomplete FCBench
inputs remain explicit coverage gaps; no substitute data is introduced.

Before execution, `generic_research prepare` records every input hash, range,
configuration, control, build hash, owner, CPU lease and budget. Initial
synthetic correctness fixtures use fixed PRNG seeds in the tests and are
separate from the real-source evidence. Each comparison uses the same source
bytes. No tuning follows held-out evaluation.

Comparisons include frozen CIX level-one, unchanged gzip-9, bzip2-9, XZ-6,
Brotli-6, each route's physical archive, all effort profiles, one-component
ablations, matched-count range/DEFLATE on identical transformed streams and
offline broad selection. Maximum-profile PPM/mixture routes may exhaust their
predeclared trial budgets and must remain FAILED/unqualified. Such failure is
not evidence about final size. Larger contiguous Golf ranges compare 16/64 KiB
blocks with zero/64 KiB decoded LZ history; their complete streams are measured.

Promotion requires complete archives and independent archive-only SHA-256
restoration with the original and materialized source paths inaccessible to
the decoder. Size losses are also decoded. GNU time measures actual command
wall time, CPU time and peak process RSS; inherited cgroups enforce no swap.
The shared scheduler reserves no more than four physical cores, eight GB RAM,
one GB temporary disk. One measured run per cell is screening evidence; cache
is uncontrolled/warm and no speed leaderboard/statistical claim is made.

Reproduction:

```sh
.venv/bin/python -m pytest tests/test_generic_pipeline.py -q
.venv/bin/python -m benchmarks.generic_research prepare
.venv/bin/python -m benchmarks.generic_research run --stratum development
.venv/bin/python -m benchmarks.generic_research run --stratum generic-regression
.venv/bin/python -m benchmarks.generic_research run --stratum heldout
.venv/bin/python -m benchmarks.generic_research run --stratum scaling
.venv/bin/python -m benchmarks.generic_research summarize
```

The scheduler retains immutable claims and reuses only rehashed verified
receipts. Failed trials are not automatically restarted. Large source and
reconstructed data are untracked; source hashes, logs and receipts are kept
in the private evidence repository. No Actions or external publication occurs.
