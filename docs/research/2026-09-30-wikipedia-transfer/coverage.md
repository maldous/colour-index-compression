# Silesia mechanism → Wikipedia coverage

This is a transfer map, not a Hutter score. The six selected Silesia mechanisms
are recorded in [coverage.json](coverage.json) with the winning lineage and code
locations. OSDB is the closest model: canonical records are split into aligned
columns, with palettes and counts transmitted, then the row-symbol sequence is
coded by **remaining-count arithmetic** (mode 3), not the mode-4 exact rank.
PAQ compresses the complete reversible transformed stream.

Current D1 uses a matched PAQ v216 `-4` tournament on enwik9 offset 0, 32 KiB:
raw 8,792 bytes; B 8,901; C 9,023; D 9,108. All archive-only decodes verified,
and all structural rows are negative. These results remain retained. Hold-outs are
untouched and the full Hutter score is unknown.

The coverage gap is D2: skeleton-relative page-field columns and article-body
families. The first body targets are infobox and table skeletons with literal body
escapes; no body result exists yet. D2 first measures alignment alone, then numeric
residuals, then per-field palette/count arithmetic against PAQ receiving the same
transformed bytes. Suggested result-schema columns
are region/hash, page eligibility/exceptions, field descriptors, palette/count
bytes, ordering/arithmetic bytes, transform bytes, PAQ payload, outer framing,
physical bytes, decode hash, and delta to the raw matched frame.
