# Boundary and override checkpoint — 2026-10-05

Benchmark and publication remain held. These are focused correctness checks against recorded source and provider identities, not compression scores or final RC acceptance.

* **RC07:** only an explicit container format excludes incompatible whole-input wires. Native block/backend tuning now retains unrelated raw, catalogue and mixed candidates. Native constraints still reach the native plan unchanged, including route incompatibility diagnostics. `selection-override-contract-v1` passed formatting and 22 tests (8 selection, 1 backend compatibility, 13 CLI/selector tests). Its subsequent all-target Clippy build encountered a GCC 13 internal compiler segmentation fault while compiling unchanged vendor libzpaq. `selection-override-clippy-v2` verified the identical frozen source and retried the identical command once; it passed. Both outcomes remain preserved.
* **RocksDB:** every runtime contract assertion became an always-executed check with a failure diagnostic. `rocksdb-contract-ndebug-v1` built Release with actual `-O3 -DNDEBUG`, verified no `-UNDEBUG`, and passed CIX SST creation, writes, reads, identity, raw fallback, missing-manager rejection, malformed-header and output-cap checks. The earlier successful v2 contract had no NDEBUG flag, so its historical assertion evidence remains valid.
* **CharLS boundary:** checked 16-bit row-stride conversion now rejects width multiplication beyond uint32 before allocation or buffer access, in both encoder and decoder. `spatial-stride-contract-v1` rebuilt the CIX bridge and passed huge-width rejection using one-byte pointers plus exact 2x2 8/16-bit round trips. This fresh provider has not silently replaced the selected distribution provider.
* **Go binding:** an explicit wrapper allocation limit defaults to 64 MiB and bounds one Go-owned output/diagnostic/stream buffer before allocation. It is separate from native codec memory, caller buffers and process RSS. `go-wrapper-budget-v1` passed all four binding tests against the hash-bound retained installed SDK. Cache size is an honestly labelled post-run check; the enclosing root scheduler enforces the shared work budget.

All jobs used the exclusive root scheduler on CPUs 8/10 (native Rust: 8/10/12/14), no swap, and the shared decimal 4 GB work ceiling. Exact commands, source/provider hashes, failures and cgroup receipts are in the respective `jobs/` directories.
