# Adapter public-API Doxygen patch v1

`adapter-sonar-context-probe-v4` reported `cxx:UndocumentedApi` on the CIX-owned declarations covered by [adapter-public-api-doxygen-v1.patch](adapter-public-api-doxygen-v1.patch). Following parser-context review, the patch was applied to the seven authorized canonical headers. It changes documentation only except for the RocksDB function parameter name, added solely to bind its Doxygen `@param` description; that name is not part of the C++ ABI.

The patch covers 37 adapter-v4 `UndocumentedApi` issues: Blosc (1), GIO (2), RocksDB (6), and SquashFS profile/userspace/kernel interfaces (28). It intentionally excludes:

- GStreamer: `adapters/gstreamer` exposes a loadable element through `GST_PLUGIN_DEFINE` in a private translation unit and has no CIX-owned installed public header or `UndocumentedApi` issue in adapter-v4. Adding comments to its static callbacks would not document a public CIX API.
- `adapters/squashfs/kernel/include/stdint.h`: a kernel build compatibility shim, not a public CIX interface.
- SevenZip: separate adapter scope, not requested for this bounded patch.

No build, parser probe, or runtime test was run. `git apply --check` accepted the reviewed patch before application, and `git diff --check` is clean afterward. The coordinator still owns parser validation. The patch does not change ABI or API behavior beyond the listed source evidence.
