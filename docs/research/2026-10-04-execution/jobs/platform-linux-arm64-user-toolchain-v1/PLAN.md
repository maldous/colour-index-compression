# Linux ARM64 user-emulation toolchain provisioning v1

This root-scheduled acquisition job prepares the first runnable local ARM64 prerequisite: a relocated AArch64 GNU C/C++ cross-toolchain and the QEMU AArch64 user emulator. It deliberately excludes Rust, a CIX bridge build, PAQ runtime enablement, an ARM guest, and host package installation.

`packages.json` is an explicit 26-package Ubuntu 24.04 closure. Every row records its immutable version, HTTPS archive URL, SHA-256, compressed byte count, and Ubuntu `Installed-Size` when the package index supplies it. The closure is 74,691,918 compressed bytes. Ubuntu's index omits `Installed-Size` for `libc6-arm64-cross` and `libc6-dev-arm64-cross`; the runner records that gap instead of guessing. After hashing all archives, it validates every tar member path and link and measures each archive's uncompressed regular-file payload before writing to the prefix.

The release scheduler retains its 4 GB shared-work bound. Before making its fresh child directory, the runner measures `benchmark-work/native-rc-check-v1` with `du -sx -B1` and refuses admission unless its current allocated bytes plus the 600,000,000-byte local cap are at most 4 GB. It uses the same allocated-byte accounting for its local prefix/work checks. The local cap covers 74,691,918 bytes of retained archives, a 512,000,000-byte extracted prefix, and 8,000,000 bytes of receipts/probes. It rejects the closure before extraction when the measured selected payload plus retained archives cannot fit, then rechecks the local cap after every extraction.

Extraction uses `dpkg-deb --extract` into the fresh job directory; it does not run `apt`, `dpkg --install`, `sudo`, maintainer scripts, or change the host package database. The QEMU archive is retained and hashed, but the runner extracts only `usr/bin/qemu-aarch64-static`; it does not retain unrelated static emulators. Download URLs are restricted to the pinned `https://archive.ubuntu.com/ubuntu/pool/...` manifest entries; redirects, byte-count mismatches, bad hashes, unsafe archive members, special members, links that lexically escape the prefix, and later writes through an earlier symlink fail the job.

The functional probes are the relocated `aarch64-linux-gnu-g++` with `--sysroot=<prefix>` (so the cross linker's absolute `/usr/aarch64-linux-gnu` paths resolve within the relocated prefix), the resulting ELF architecture, and `qemu-aarch64-static --version`. The receipt hashes the runner/spec/manifest and the current CIX PAQ v215/v216 bridge CMake/source inputs before and after. Those CIX hashes identify planned downstream bridge inputs; they are not a bridge compilation or ARM64 qualification result.

Root dispatches this runner through the established release scheduler with `spec.json`, using physical CPUs 8 and 10. The spec sets the scheduler's shared-work ceiling to 4 GB; the runner enforces the narrower 600 MB new-work allocation. This recipe has not been run.
