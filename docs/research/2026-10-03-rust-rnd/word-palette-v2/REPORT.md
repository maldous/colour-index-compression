# Word palette: single-run mechanism screen

Six frozen configurations passed fresh native-candidate and selected-candidate archive-only restoration. All inputs are 8,192 bytes. This is an experimental block representation, not production streaming.

| Control | Plain CIXG1 identity | Identity in WPV2 | Palette in WPV2 | Palette minus matched identity |
|---|---:|---:|---:|---:|
| strong | 204 | 273 | 256 | -17 |
| weak | 1,296 | 1,365 | 1,413 | +48 |
| absent | 8,287 | 8,356 | 8,526 | +170 |

The palette saves 17 bytes under identical framing on the strong control. It loses 48 bytes on weak and 170 bytes on absent opportunity. The 69-byte experimental outer framing/instructions make its strong result (256 bytes) larger than the plain production CIXG1 archive (204 bytes). **No complete-archive production win is established; do not enable this wrapper in the selector.**

The dictionary, five-bit indices, raw exceptions and tail are included in representation bytes; nested CIX framing plus 35-byte instructions and 34-byte outer header are included in complete bytes. The absent identity selects its 8,261-byte raw WPV2 fallback; its 8,356-byte native candidate was independently decoded too. Matched comparisons above use native candidates, never substitute raw.

Native encode screening observations were 11.69–17.74 ms and native decode 10.56–12.67 ms, one measurement each. These include process launch, GNU time, timeout and prlimit; they exclude outer dictionary construction/selection. Batch wall time, all transforms and verification are separately recorded (0.333 s inside driver, 0.553 s supervisor). No throughput generalisation or averages are claimed.

One CPU20, cpu.max=100000/100000, 768 MiB aggregate memory, no swap, 2 MiB retained temp cap. Child encode RSS was 6.0–6.25 MiB; sampled supervisor cgroup high-water was 27,369,472 bytes including orchestration. All cgroup memory events max/oom/oom_kill were zero. Retained run files were 382,564 bytes; no temporary file spooling of an unknown-length source was tested.

Source and binary SHA, exact native flags, fixture hashes, archives, independent restored hashes, raw GNU-time receipts and constraints are in freeze.json, execution-binding.json, results.json and raw/. Generated bytes/binaries remain outside Git. `schedule.py` and `run_batch.py` reproduce the frozen screen from repository root using existing binaries; unique unit/output names must be used for a separate experiment.

Next: compact reuse within an existing native format could remove wrapper overhead, but requires separate decoder-contract and held-out qualification. Widths2/4, streaming, real datasets, malformed-frame tests and selector admission remain unqualified.
