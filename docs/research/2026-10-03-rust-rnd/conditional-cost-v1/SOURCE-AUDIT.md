# Conditional-cost-v1 source audit

Prepared from commit `8439f4c414b06d0ff328c57c6bbc3b065f30c05a`; no build, test, benchmark, or measurement has been run for this experiment.

`src/rank.rs` supplies the actual matched codecs. `encode_composition_tiles` emits 1024-byte type-class tiles. At this frozen length `encode_type_class` selects canonical rank mode 0. `encode_count_range` emits the same `encode_type_class_header`, then mode 1 and an arithmetic stream whose interval is the remaining histogram. Both decode through `decode_composition_tiles`. The pre-existing `count_range_keeps_pre_refactor_bytes_and_round_trips` source test documents byte compatibility of the count-range assembly.

`src/main.rs` maps these to payload coders 2 and 5. Its automatic `cix` route admits coder 2 only below its entropy gate, while coder 5 is an explicit `count-range` backend. This experiment calls the public functions directly, so no selector, entropy estimate, portfolio choice, block policy, parallel path, filename, or input identity affects the comparison.

`src/adaptive.rs`, `src/ppm.rs`, and `src/stateful.rs` use the shared arithmetic primitives but are excluded: adding a predictive model would give extra side information or a different causal state to one contender. Consequently ideal prediction and quantized-CDF probability costs are inapplicable here. The recorded `arithmetic_stream_bits` is only the stored range bit length, including its termination. The 2026-09-29 conditional-composition note supplies the same interpretation guardrail: a count-informed composition and count-informed arithmetic coder share a conditional state space.

The four generators preserve exactly the same histogram inside every physical tile. They deliberately vary only ordering: interleaved two-lane symbols, 64-byte symbol clusters, a fixed 16-symbol period, and a deterministic shuffled multiset. The frozen generated bytes must be materialized through `conditional_cost_v1 generate CASE INPUT` and SHA-256 recorded before the paired measurements. A result that varies by ordering is a finite coder effect, since the ideal conditional type-class cost is equal; neither codec is expected to learn the stated ordering relationship.
